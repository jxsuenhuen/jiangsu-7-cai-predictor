安装到 Windows / iPhone

Windows：用 Edge 或 Chrome 打开本站，从浏览器菜单选择“安装此站点为应用”。iPhone：用 Safari 打开本站，点分享 → 添加到主屏幕 → 添加。首次联网打开后可离线查看已缓存页面和开奖数据。预测记录仅保存在当前设备，不会跨设备同步。

预测为历史统计实验，无法可靠预测随机开奖，不代表中奖概率提高。预计开奖日期可能受休市影响，以官方公告为准。
